# M3 Evidence Intelligence & Hybrid Retrieval Documentation

## 1. M3 Overview & Objectives

Milestone M3 advances the **Zyntrix BIS Compliance Compiler** from standard vector retrieval to **Evidence Intelligence**, implementing:
1. **Hybrid Retrieval**: BM25 Lexical search + pgvector Dense Vector similarity.
2. **Deterministic Reranking**: Cross-matching reranker boosting exact clause, standard, and requirement code mentions.
3. **Evidence Extraction & Normalization**: Parsing structured parameters (`tested_heat_retention_temp`, `leakage_test_result`, `material_grade_verified`) from lab reports and datasheets with unit normalization (`60 deg C` $\to$ `60.0 C`).
4. **Evidentiary Conflict Detection**: Flagging contradictory values between competing documents (e.g. Datasheet claims 65°C vs Lab Report reports 54°C $\to$ `CONFLICTING_EVIDENCE` + `EXPERT_REVIEW`).
5. **Test Roadmap & Laboratory Knowledge**: Structured testing roadmaps and verified NABL/BIS laboratory registries.
6. **Expanded Development Benchmark ($N=10$)**: Honest measurement of Recall@1/3/5, MRR, ablation comparisons, and error classification.

The core boundary remains inviolate:
> **"RETRIEVE $\to$ VERIFY $\to$ DECIDE $\to$ EXPLAIN. The LLM extracts data and explains reasoning; deterministic logic and verifiable evidence establish compliance claims. LLM Decision Authority = 0."**

## 2. Hybrid Retrieval Architecture

```
USER QUERY / ENRICHED PRODUCT DNA
            ↓
    METADATA FILTER (Verified-only / Standard Number / Status)
            ↓
    ┌───────────────────────────┬───────────────────────────┐
    │ BM25 Lexical Search       │ pgvector Dense Vector     │
    │ (Okapi BM25: k1=1.5,b=0.75)│ (Cosine Similarity)       │
    └─────────────┬─────────────┴─────────────┬─────────────┘
                  ▼                           ▼
            CANDIDATE UNION & HYBRID SCORING
            score = (alpha * norm_lexical) + (beta * norm_dense)
                          ↓
            EXACT MATCH & RELEVANCE RERANKER
            (Clause # bonus, Standard title bonus, Term hits)
                          ↓
            CONTEXT WINDOW (Parent Clause Resolution)
                          ↓
            TOP-K RANKED CLAUSES WITH PROVENANCE
```

## 3. Evidence Extraction & Conflict Detection

- **Structured Evidence Model** ([evidence_extractor.py](../backend/app/services/gap_analysis/evidence_extractor.py)):
  - Fields: `evidence_id`, `evidence_type`, `source_text`, `attribute`, `raw_value`, `normalized_value`, `unit`, `authority`, `confidence`.
  - Authority Levels: `LAB_REPORT` (high evidentiary authority), `CERTIFICATE`, `MANUFACTURER_DOCUMENT`, `USER_ASSERTED`.
- **Conflict Handling**:
  - When two or more documents report divergent values for the same attribute, the engine emits an explicit conflict notice.
  - The gap analysis engine maps this to `ComplianceStatus.CONFLICTING_EVIDENCE` and `RecommendedAction.EXPERT_REVIEW`.

---

## 4. Laboratory Knowledge & Testing Roadmap

- **Testing Roadmap Compiler** ([test_roadmap.py](../backend/app/services/laboratory/test_roadmap.py)):
  - Compiles standard testing roadmaps (test method standard, required apparatus, pass criteria, and BIS Product Manual sampling guidelines).
  - *No false claims*: Produces a testing roadmap for manufacturers without claiming physical execution.
- **Verified Laboratory Registry**:
  - Exposes official NABL-accredited BIS testing centers (e.g. Central Laboratory CLD Sahibabad, National Test House NTH).
